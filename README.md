# 連休プランナー

有給と祝日と会社の休みを組み合わせて、連休を計画できる Web アプリです。登録なしで使えます。

## 起動方法

```sh
npm install
npm run dev
```

http://localhost:3000 を開きます。

## 祝日の更新

祝日は内閣府の CSV から取り込み、`src/data/holidays.json` に同梱しています。更新するときは次を実行します。

```sh
npm run holidays:fetch
```

毎月の自動取り込みは、成功するたびに「確認した日」（`checkedAt`）を `src/data/holidays.json` に書いてコミットします。祝日の内容が変わらない月も、コミットが 1 件できます。

取り込みが「既存の祝日が消えています」で失敗したときは、次の順で進めます。

1. 内閣府の発表で、その祝日が実際に移った、または無くなったことを確かめる
2. `src/data/holidays.json` から、該当の日付の行を手で消す
3. `npm run holidays:fetch` を実行する
4. 差分を見てコミットする
