# 連休プランナー

有給と祝日と会社の休みを組み合わせて、連休を計画できる Web アプリです。登録なしで使えます。

## 起動方法

```sh
npm install
npm run dev
```

http://localhost:3000 を開きます。

## 設定画面

ヘッダーの「設定」から `/settings` を開き、有休の付与日と日数、所定労働時間、週の始まり、会社の休日、休暇の種類を直せます。

## 記録の保存

記録（設定と日程）は、開いているブラウザの保存領域（`localStorage`）にだけ置きます。運営には送りません。

- ブラウザのサイトのデータを消すと、記録は失われます。運営側に写しはありません
- ほかの端末やブラウザとは共有されません（書き出しと読み込みは、次の計画で作ります）
- 保存できないブラウザ（プライベートブラウズなど）でも候補は見られますが、閉じると入れた内容が消えます

## 祝日の更新

祝日は内閣府の CSV から取り込み、`src/data/holidays.json` に同梱しています。更新するときは次を実行します。

```sh
npm run holidays:fetch
```

毎月の自動取り込みは、成功するたびに「確認した日」（`checkedAt`）を `src/data/holidays.json` に書いてコミットします。祝日の内容が変わらない月も、コミットが 1 件できます。

取り込みが「既存の祝日が消えています」で失敗したときは、次の順で進めます。

1. 内閣府の発表で、その祝日が実際に移った、または無くなったことを確かめる
2. `src/data/holidays.json` から、該当の日付の行を手で消す。最後の行を消したときは、1 つ前の行の末尾のカンマも消す（残すと JSON として読めず、取り込みが失敗する）
3. `npm run holidays:fetch` を実行する
4. 差分を見てコミットする
