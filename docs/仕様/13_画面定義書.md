## 2. 画面とモーダルの一覧

画面は 2 枚。入力と確認は、画面の上に重ねる「モーダル」で行う。モーダルはスマホでは下から出し、PC では画面の中央に出す。

| ID | 名前 | 種類 | 開き方 | 対応する要求 |
|---|---|---|---|---|
| S-1 | 主な画面 | 画面 | URL を開く | F-501 |
| S-2 | 設定画面 | 画面 | S-1 の「設定」、祝日の 1 行の「くわしく」 | F-504 |
| M-1 | 日程に入れるモーダル | モーダル | 候補の「日程に入れる」（祝日のない月の候補を含む） | F-205、F-206 |
| M-2 | 日程のモーダル | モーダル | 日程の行、「＋ 日を足す」 | F-302、F-303 |
| M-3 | 付与日と日数を入れるモーダル | モーダル | 誘いのカード、「日数を入れる」、S-2 の有休の行 | F-101、F-405 |
| M-4 | 会社の休日のモーダル | モーダル | S-2 の会社の休日の行、「＋ 会社の休日を足す」 | F-103 |
| M-5 | 休暇の種類のモーダル | モーダル | S-2 の休暇の種類の行、「＋ 休暇の種類を足す」 | F-104 |

主な画面には 2 つの状態がある。

- **設定なし**: 付与日を入れていない。持ち分は出さず、入力を誘う（F-106）
- **設定あり**: 付与日を入れた。持ち分を出す

2 つの状態を分けるのは付与日の有無だけで、変わるのは持ち分の出し方だけ。候補と連休の計算には、付与日がなくても、登録してある会社の休日と日程を入れる（F-103、F-207、R-1）。足した休暇の種類の持ち分も、有休の付与日がないあいだは出さない（その種類に自分の付与される日があっても同じ。有休の付与日を入れるまでは、持ち分をまとめて出さない）。

最初に返す HTML（N-04）には次のものを入れる。

- サービスの説明文（§3.1）
- ビルドした年の 1 月から、祝日が確定している期間までの四半期ごとの見出しと、候補の一覧（土日と祝日だけで計算したもの。実装計画 1 の `staticCandidateGroups`）
- 祝日の 1 行（§3.10）

月カレンダー、長めの休暇の 1 行、持ち分、日程は、端末で描く。端末は記録を読んだあと、今日が入る四半期から 4 つに絞り、記録を入れて計算し直した内容に差し替える。差し替えるまでのあいだ、持ち分の場所は高さを保ったまま空けておき、誘いのカードを一瞬出すことはしない。スマホと PC の配置は CSS で切り替え、HTML は 1 つにする。

HTML に入れた候補の一覧は、見えない状態で始め、端末が差し替えを終えてから見せる（オーナー決定）。年の初めからの一覧が一瞬見えて切り替わるのを避けるため。見えない状態は `visibility: hidden` で作り、場所の高さは保つ。スクリプトが動かない環境では、`<noscript>` の中の style でこれを打ち消し、一覧をそのまま見せる（持ち分の空けた場所も詰める）。見えない状態で始めた文字を検索エンジンがどう扱うかは、実装計画で確かめる。

幅 1024px 未満をスマホの配置、1024px 以上を PC の配置とする（bassdrill と同じ境目）。

## 3. 主な画面（スマホ）

### 3.1 構成

上から順に並べる。

```
┌──────────────────────────────┐
│ 連休プランナー           設定 │  ヘッダー
├──────────────────────────────┤
│ 有休 残り                     │  持ち分のカード（§3.2）
│ 9日2時間                      │  設定なしのときは誘いのカード（§3.9）
│ 予定 2日・未割り当て 7日2時間 │
├──────────────────────────────┤
│ 長めの休暇                    │  長めの休暇の 1 行（§3.3）
│ [10〜12月 あり][1〜3月 まだ]… │
├──────────────────────────────┤
│‹前│2026年 │2027年│2027年│2027年│  四半期のタブ（§3.4）
│   │10〜12月│1〜3月│4〜6月│7〜9月│
├──────────────────────────────┤
│ 2026年 10〜12月               │  タブの中身（§3.5）
│ 長めの休暇: 12/26〜1/3（9連休）│   長めの休暇
│ [10月] [11月] [12月]          │   月カレンダー（§3.6）
│ 候補                          │   候補（§3.7）
│ 日程               ＋ 日を足す │   日程（§3.8）
├──────────────────────────────┤
│ 祝日は内閣府の公表データです…  │  祝日の 1 行（§3.10）
└──────────────────────────────┘
```

ヘッダーは画面の上に固定しない。スクロールすると一緒に流れる。

設定なしのときは、ヘッダーのすぐ下にサービスの説明文を 1〜2 行で出す（N-04。文は `APP_DESCRIPTION`）。説明文は、端末で動く主な画面の部品（`Planner`）が描く。最初に返す HTML には必ず入り（記録を読み終えるまでは設定なしと同じ内容なので、検索エンジンには説明文が届く）、記録を読み終えて付与日があるときだけ隠す。

### 3.2 持ち分のカード

休暇の種類ごとに 1 枚出す（F-401）。出すのは、今日が入る付与年の値。足した休暇の種類は、その種類の付与される日で区切った付与年で見る（R-13）。

| 行 | 内容 | 例 |
|---|---|---|
| 1 行目 | 休暇の種類の名前と「残り」 | 有休 残り |
| 2 行目 | 残りの量。大きな文字 | 9日2時間 |
| 3 行目 | 予定の量と、未割り当ての量 | 予定 2日・未割り当て 7日2時間 |

- 量の書き方は R-11 のとおり（「9日2時間」。モックでは日と時間のあいだを詰めている。R-11 の「9 日と 2 時間」とどちらにするかは §8 で決める）
- 未割り当てが負のときは、「未割り当て」の代わりに「不足 1日」と出し、警告の色にする（F-211、R-11）。0.5 分の端数で絶対値が 1 分に満たないときは「不足」を出さず「未割り当て 0日」とする
- 使える期間のある休暇の種類は、3 行目に期間を添える（例: 「7〜9月」）。残りが 0 なら「使い切り」と出す
- カードが 2 枚のときは横に並べる。3 枚以上は横にスクロールする
- 年 5 日の取得に届いていないあいだ、有休のカードの下に 1 行出す（F-404、R-18）。例: 「年 5 日の取得まで あと 1日（取得済み 3日・予定 1日）」。ふだんは補助の文字の色で出し、付与年の末日まで 90 日以内は警告の色で出す。予定を含めて 5 日に届けば出さない。付与年の終わりが近いことや、使える期間の終わりが近いことを知らせる行は置かない（オーナー決定。残りと未割り当てはいつも出ている）
- 新しい付与年が始まったあと、その付与年の日数をまだ確かめていないあいだ、有休のカードの下に 1 行出す（F-407）。文は「新しい年になりました。付与日数と使える日数を確かめる」で、押すと M-3（始まった付与年）を開く。出すのは、今日が入る付与年に設定が無く、それより前の付与年に設定があるとき。その付与年のモーダルを保存すると消える（付与年が始まる前に「日数を入れる」で入れてあった年にも出さない）。年 5 日の取得の 1 行より上に置く

### 3.3 長めの休暇の 1 行

持ち分のカードのすぐ下に置く（P-3）。見出し「長めの休暇」を 1 回だけ書き、その下に、タブに並んでいる 4 つの四半期の状態を小さな札で並べる。

- 札の文言: 「10〜12月 あり」「1〜3月 まだ」。あり・まだで色を変える
- 判定は R-14
- 会社の休日も日程も 1 件も登録していないときは、見出しを「長めの休暇（土日と祝日だけで計算）」とする
- 並べるのは、いつも今日が入る四半期からの 4 つ。「‹ 前」でタブがずれても、この行は変えない
- 札は押せない（押してその四半期のタブを開く動きは足さない）

### 3.4 四半期のタブ

- 左端に「‹ 前」、続けて 4 つの四半期を並べる。タブは 2 行で、上に年（「2026年」）、下に月（「10〜12月」）
- 最初に開くのは、今日が入る四半期
- 「‹ 前」を押すと、タブの並びが 1 四半期ぶん前へずれ、いちばん左の四半期を開く。前へずれているあいだは、右端に「次 ›」を出す。「次 ›」で 1 四半期ぶん戻る。前へ動けるのは、日程がある最も古い四半期と、今日が入る付与年が始まった四半期の、早いほうまで。付与日を入れていないときは、日程がある最も古い四半期まで。前へ動ける先がないときは「‹ 前」を出さない
- タブの題に、長めの休暇の有無や付与日は入れない（オーナー決定。§3.3 と §3.6 に出す）
- タブの段はスクロールしても画面の上に張り付く（F-507）
- 持ち分のカードが画面の外へ流れたあとは、タブの段のすぐ上に、持ち分を 1 行に縮めたものを一緒に張り付ける（F-401。オーナー決定）。例: 「有休 残り 9日2時間・未割り当て 7日2時間」。休暇の種類が 2 つ以上あるときは有休だけを出す。未割り当てが負のときは「不足 1日」と警告の色で出す。設定なしのときは出さない
- 過ぎた四半期（末日が今日より前の四半期）の中身は、見出し、長めの休暇、月カレンダー、日程だけにする。候補の欄と、カレンダーの候補の印は出さない（R-4 により、今日より前の日は候補にならない）。「＋ 日を足す」は出す（入れ忘れた休みを、あとから記録できるようにする）。長めの休暇の文言は、過ぎた四半期では「まだない」が合わないので、§8 で決める

### 3.5 タブの中身

上から、見出し、長めの休暇、月カレンダー、候補、日程の順（オーナー決定）。

- 見出し: 「2026年 10〜12月」
- 長めの休暇: あるときは「長めの休暇: 12/26〜1/3（9連休）」と「あり」の札。ないときは「長めの休暇: まだない」（F-403）

### 3.6 月カレンダー

その四半期の 3 か月を横に並べる（F-502）。

- 月曜始まり。見出しは「10月」。曜日の行は「月火水木金土日」。設定で日曜始まり（「日月火水木金土」）に変えられる（F-108）
- 日ごとの色分けは次のとおり。重なったときは上の行を優先する

| 順 | 種類 | 見た目（仮） |
|---|---|---|
| 1 | 取得済みの日程 | 塗りつぶし（主色） |
| 2 | 予定の日程 | 枠線（主色） |
| 3 | 候補の休む日 | 枠線（注意の色）と薄い地 |
| 4 | 会社の休日 | 薄い地（青系） |
| 5 | 土日・祝日 | 薄い地（赤系） |

- 半日・時間単位の日程の日も取得済み・予定の印で出す
- 候補の印を付けるのは、§3.7 で開かずに見えている候補（組の中で休む日数がいちばん少ないもの）の休む日だけ。まとめた行の中の候補と、祝日のない月の候補には付けない
- 付与日は上の色分けとは別に、日付に紫の枠を重ねる（オーナー決定）。その付与日が、今日より後に来る付与日（次の付与年の始まり）のときは、カレンダーの下に 1 行添える。今の付与年の始まりに当たる付与日には、枠だけを付けて 1 行は添えない
  - 次の付与年の日数を入れていないとき: 「5/1 から次の付与年（前の年と同じ 14日で計算中）」と「日数を入れる」。「日数を入れる」は M-3 を開く
  - 入れたあと: 「5/1 から次の付与年（有休 16日）」
- カレンダーの下に凡例を置く。その四半期に出ている種類だけを並べる
- 日付のマスは押せない。日を足すのは「＋ 日を足す」から（スマホでは 1 マスが 15px ほどで、狙った日を押せない）

### 3.7 候補

見出し「候補」の下に、その四半期の候補の組を R-7 の順で並べる。候補 1 件は次の形の 1 行で出す。

| 部分 | 内容 | 例 |
|---|---|---|
| 1 行目 | 休む日と曜日、連休の日数 | 11/20(金) を休むと 4連休 |
| 札 | 5 連休以上なら「長め」（F-204）。未確定なら「祝日が未確定」（F-210） | |
| 2 行目 | 連休の期間。休む日が 2 日以上なら、使う日数（「2日使う」）（F-202）。次の付与日以降の日を含むなら「次の付与年から引く」（F-209。付与年は、その候補で引く休暇の初期値になる種類の区切りで見る） | 11/20〜11/23 |
| ボタン | 「日程に入れる」。M-1 を開く | |

- 休む日が 2 日以上のときは「12/28(月)・12/29(火) を休むと 9連休」と書く
- 1 つの組は次のように出す（F-203。オーナー決定）
  - 組の中で休む日数がいちばん少ない候補は、全部を 1 件 1 行で出す（連休の長い順）。たとえば勤労感謝の日（11/23）の組なら、11/20(金) と 11/24(火) の 2 行
  - 残りの候補は、「もっと多く休む取り方（7）」のような 1 行にまとめる。押すと開き、休む日数の少ない順（R-7）に 1 件 1 行で並ぶ。もう一度押すと閉じる
  - まとめた中に 5 連休以上があれば、その 1 行に「長めあり」と添える
- 未割り当てが足りない候補も出す。2 行目に「有休が 1日足りません」と添える（F-211）。判定は、休む日が入る付与年ごとに、その付与年の未割り当てで行う（次の付与年の未割り当ては R-13 で計算した値で数える）。休暇の種類は M-1 で初期値になる種類（ふつうは有休。F-208 に当たるときはその休暇）で見る
- 祝日のない月の候補（R-8）は、ふつうの候補の下に、まとめた行と同じ形の 1 行で出す（オーナー決定）。例: 「12月は祝日がありません。金曜か月曜を休むと 3連休（8）」。押すと開き、R-8 の選択肢が 1 日 1 行（「12/4(金) を休むと 3連休」「12/4〜12/6」「日程に入れる」）で、日付の早い順に並ぶ
- その四半期に候補が 1 つもないときは「この四半期の候補はありません」と出す

```
候補
 11/20(金) を休むと 4連休              [日程に入れる]
 11/24(火) を休むと 4連休              [日程に入れる]
 もっと多く休む取り方（7）・長めあり ▸
 12月は祝日がありません。
 金曜か月曜を休むと 3連休（8）      ▸
```

### 3.8 日程

見出し「日程」の右に「＋ 日を足す」を置く（M-2 を開く）。その下に、その四半期の日付の日程を、日付の早い順に並べる。

- 1 日 1 行（オーナー決定）。行の中身は次のとおり

| 部分 | 内容 | 例 |
|---|---|---|
| 1 行目 | 日付と曜日、量、予定の名前 | 12/28(月) 1日 年末年始 |
| 2 行目 | 状態（予定・取得済み）。有休以外なら休暇の種類の名前 | 予定 |
| 右端 | 「›」。行を押すと M-2 を開く | |

- その日が 3 日以上の連休に入るとき（F-304）
  - 同じ連休に入る日程が 2 件以上なら、連休の見出し（「12/26〜1/3 の 9連休」と、5 連休以上なら「長め」の札）を 1 行置き、その下に日程を並べる
  - 1 件だけなら見出しを置かず、2 行目に「取得済み・10/31〜11/3 の 4連休」のように添える
- 日付を過ぎた予定は 2 行目を「予定・日付を過ぎています」として警告の色にし、右端を「取得済みにする」のボタンに替える（F-305）。押すと、モーダルを挟まずに取得済みになる。行のほかの場所を押すと M-2 を開く
- 休みの日と重なった日程（R-17）は、2 行目に「休みの日と重なっています」を警告の色で添える。行を押して M-2 を開き、利用者が消す
- 日程が 1 件もないときは「まだありません」と出す

### 3.9 設定なしのとき

持ち分のカードの場所に、誘いのカードを置く（オーナー決定）。

```
┌──────────────────────────────┐
│ 有休の残りを出す              │
│ 付与日と日数を入れると、残りと、│
│ まだ日を決めていない日数が出ます│
│ [付与日と日数を入れる]         │
└──────────────────────────────┘
```

- ボタンは M-3 を開く
- 設定なしでも、候補を日程に入れる操作と、日を足す操作はできる。M-1 では持ち分に関わる行（引く休暇の残り、未割り当ての変化）を出さず、代わりに「付与日と日数を入れると、残りが出ます」を出す（M-2 には持ち分に関わる行が無い）

### 3.10 祝日の 1 行

画面のいちばん下に出す（F-605）。

- タブを置かない。今日が入る四半期から 4 つの節を、開いたまま縦に並べる
- 持ち分のカードと、長めの休暇の 1 行は、横に並べる
- 四半期の節は 2 列。左に見出し、長めの休暇、月カレンダー、凡例、付与日の 1 行。右に候補と日程
- 節の見出し（「2026年 10〜12月」）は、その節をスクロールしているあいだ、画面の上に張り付く（F-507）
- 持ち分のカードが画面の外へ流れたあとは、スマホと同じ持ち分の 1 行を、画面の上に張り付ける（F-401）。節の見出しは、その 1 行のすぐ下に張り付く
- 過ぎた四半期はいちばん下の祝日の 1 行と同じ段の右端に置いた「過ぎた四半期の記録を見る」から開く（P-5。オーナー決定）。押すたびに、1 つ前の四半期の節を、並びのいちばん上に足す。足したあとは、その節まで画面を動かす。過ぎた四半期の節の中身は §3.4 と同じ（候補の欄を出さない）。前へ動ける先がないときは出さない。動ける限りは §3.4 と同じ
- 本文の幅は最大 960px とし、画面の中央に置く
- モーダルは画面の中央に出す。ボタンはモーダルの右下に並べる。「この日程を消す」のような消す操作は、左下に離して置く

## 5. モーダル

共通の決まり。

- モーダルは標準の `<dialog>` で作る。閉じ方は 3 つ。「やめる」を押す、モーダルの外を押す、Esc キーを押す（キーボードのある端末なら、PC に限らず同じ）。どれも、入れかけの内容を捨てる。モーダルの外を押して閉じるのは、押すのも離すのもモーダルの外のときだけ（モーダルの中の文字をドラッグで選び、外で離したときは閉じない）
- 確定のボタンは 1 つで、主色で塗る。入れた内容が受け付けられないあいだは押せない見た目にし、理由を該当の欄の下に出す（文言は §8.3）
- モーダルを開いているあいだ、下の画面は暗くし、スクロールさせない

### 5.1 M-1 日程に入れるモーダル

候補の休む日を、予定として日程に入れる（F-206）。

| 行 | 内容 | 例 |
|---|---|---|
| 題 | 日程に入れる | |
| 休む日 | 休む日と合計の量 | 11/20(金) 1日 |
| 連休 | 期間と日数 | 11/20〜11/23 の 4連休 |
| 引く休暇 | 休暇の種類と、その残り。種類が 2 つ以上あるときだけ選べる | 有休（残り 9日2時間） |
| 未割り当て | 入れる前と後。休む日が入る付与年の値 | 7日2時間 → 6日2時間 |
| 予定の名前 | 任意の入力欄 | |
| ボタン | 「予定に入れる」「やめる」 | |

- 休む日が付与日をまたぐときは、未割り当ての行を付与年ごとに 2 行出す（例: 「今の付与年 7日2時間 → 6日2時間」「次の付与年 14日 → 13日」）（F-209）
- 引く休暇の初期値は、次の両方に当たる休暇の種類にする（F-208）。当たるものが無ければ有休。(1) 使える期間があり、その候補の休む日が全部その期間に入る。(2) 休む日が入る付与年ごとに、その種類の未割り当てが、その付与年に入る休む量以上ある。まとめて取る休暇の印がある種類は、初期値にしない（その候補は F-212 で別に出す）。当たる種類が 2 つ以上あるときは、設定画面の並びで上にあるもの。付与日を入れていないときは持ち分を数えられないので、有休のまま。利用者はいつでも選び直せる。「＋ 日を足す」から手で入れるときは、使える期間の外の日でも、その種類を選んで保存できる
- 引く休暇の残りは、休む日がすべて 1 つの付与年に入るときだけ添える。付与日をまたぐときと、付与日を入れていないときは、休暇の種類の名前だけを出す（付与年ごとの量は、未割り当ての行で分かる）
- 入れると未割り当てが負になるときも入れられる。未割り当ての行を「7日2時間 → 不足 1日」と警告の色で出す（F-211）
- 「予定に入れる」を押すと、モーダルを閉じ、日程の欄に行が増える。休む日の数だけ、1 日分の日程を作る。予定の名前は全部の日に同じものを入れる

### 5.2 M-2 日程のモーダル

### 5.3 M-3 付与日と日数を入れるモーダル

| 行 | 内容 | 備考 |
|---|---|---|
| 題 | 有休の付与日と日数 | 題の下に、どの付与年の分かを出す（例: 「2026/5/1〜2027/4/30 の分」）。初めて入れるときは、今日が入る付与年の分になる |
| 付与日 | 月と日の選択 | 日の選択肢は選んだ月に合わせる。2 月は 1〜28（R-12）。月を変えて、選んでいた日がその月に無くなったときは、その月の末日に直す。初めての入力のときだけ欄にし、ほかの開き方では文字で出す |
| 1 年に付与される日数 | 日数 | 次の付与年では、初期値は R-13 の付与日数 |
| この年に使える日数 | 日と時間 | 開き方で変わる（下の箇条書き） |
| 説明 | 入れた内容は、このブラウザの中にだけ保存します。運営には送られません。 | オーナー指定。安心のため |
| ボタン | 「残りを出す」「やめる」 | 初めての入力のとき以外は「保存する」 |

行は、開き方で変わる。

- 初めての入力（誘いのカードから）: 付与日は月と日の選択。この年に使える日数は日と時間の欄で、初期値は付与日数と同じ。利用者が触るまでは、付与日数に合わせて動く。欄の下に「前の年から繰り越した分があれば、足した数に直してください」を出す
- 次の付与年（「日数を入れる」から）: 付与日は文字で出す。この年に使える日数は欄にせず、文で出す（「16 日 ＋ 今の年の残り（いまは 4 日と 2 時間）」）。付与日数の欄を変えると、文の日数も変わる
- 始まった付与年（設定画面から）: 付与日は文字で出す。この年に使える日数は日と時間の欄で、初期値は R-13 で計算した持ち分。会社の数字と違うときだけ直す
- 付与日を直す（設定画面の付与日の行から）: 初めての入力と同じ欄を、いまの値を入れた状態で出す。ボタンは「保存する」。付与日を変えて保存すると、今日が入る付与年の設定は入れた値になり、ほかの付与年（次の年、過ぎた年）の設定は消える。日程は消さず、新しい付与年の区切りで数え直す。付与日をいまと違う月日にしていて、消える設定があるあいだは、付与日の欄の下に警告の色で「付与日を変えると、ほかの年に入れた日数は消えます。日程は消えません」と出す（確かめるモーダルは挟まない）。付与日を変えて保存するときは、「この年に使える日数」の欄に出ている数を、触らなくてもそのまま保存する（計算した数と同じなら上書きにしない）
- 「この年に使える日数」を利用者が触らなかったとき、または計算した値と同じ数のまま保存したときは、上書きを持たない（計算に任せる）。ただし、その付与年にすでに上書きがあるときは、触らずに保存しても、その上書きをそのまま保つ（開き直して保存しただけで数字が変わらないようにする）
- 「この年に使える日数」の日の欄が空のときは、保存できない（付与日数の欄が空のときと同じ扱い。誤りの文は出さず、ボタンを押せなくする）。時間の欄が空のときは 0 時間として扱う
- 保存先を伝える説明はこのモーダルと、S-2 の「記録の持ち出し」にだけ置く（オーナー決定）

### 5.5 M-5 休暇の種類のモーダル

| 行 | 内容 | 備考 |
|---|---|---|
| 題 | 休暇の種類 | |
| 名前 | 入力欄 | 有休は名前を変えられない |
| 日数 | 1 年に付く日数 | 有休では出さない（付与年ごとの値を M-3 で入れる） |
| 使える期間 | 開始と終了の月日。任意 | |
| 付与される日 | 「有休と同じ」か、月と日の指定 | 初期値は「有休と同じ」。日の選択肢は M-3 の付与日と同じ（2 月は 28 日まで） |
| まとめて取る休暇 | チェック。「営業日で連続して、全部の日数を 1 回で取る休暇」と添える | 初期値は付けない。有休では出さない |

- 使える期間は、開始が終了と同じか前のときだけ受け付ける。年をまたぐ期間（12/1〜1/31 など）は入れられない。2 月 29 日は選べる
- 使える期間を入れるときの初期値は、開始・終了とも今日の月日。付与される日を月と日で指定するときの初期値は 4月1日

## 6. 設定画面（S-2）

## 8. 文言

### 8.1 方針

モックと本書の文言は仮のもの。要求定義書 §4.1 の用語は文書の中で意味をそろえるための言葉で、前提を知らない利用者には伝わらない（オーナー指摘）。配置が固まったあと、画面に出す言葉をまとめて決め、下の表を埋める。決まるまでは、実装でも仮の文言を使い、文言を 1 か所（定数のファイル）に集めておく。

題と説明文は「有給」を使う（要求定義書 §9）。画面の中を「有休」「有給」のどちらにそろえるかは未決（§9 V-1）。
