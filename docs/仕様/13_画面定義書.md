## 1. 配置の原則

配置で迷ったら、次の順で決める。要求定義書 §5 の価値（C-1〜C-5）を画面に写したもの。

| ID | 原則 | 元 |
|---|---|---|
| P-1 | スマホを主に考える。片手で候補を選んで日程に入れられる | F-503 |
| P-2 | 開いたら、休みの形（月カレンダー）と候補が先に見える | C-1 |
| P-3 | 持ち分と、長めの休暇がまだない四半期は、どの四半期を見ていても目に入る | C-3 |
| P-4 | 入れる・直す操作は、面で中身を確かめてから確定する | オーナー決定 |
| P-5 | 頻繁に押されない要素を、画面の中心付近の目立つ場所に出し続けない | オーナー指摘 |
| P-6 | 画面の文言は、前提を知らない利用者に伝わる言葉で書く。要求定義書 §4.1 の用語をそのまま出さない（§8） | オーナー指摘 |

## 2. 画面と面の一覧

画面は 2 枚。入力と確認は、画面の上に重ねる「面」で行う。面はスマホでは下から出し、PC では画面の中央に出す。

| ID | 名前 | 種類 | 開き方 | 対応する要求 |
|---|---|---|---|---|
| S-1 | 主な画面 | 画面 | URL を開く | F-501 |
| S-2 | 設定の面 | 画面 | S-1 の「設定」 | F-504 |
| M-1 | 日程に入れる面 | 面 | 候補の「日程に入れる」 | F-206 |
| M-2 | 日程の面 | 面 | 日程の行、「＋ 日を足す」 | F-302、F-303 |
| M-3 | 付与日と日数を入れる面 | 面 | 誘いのカード、「日数を入れる」、S-2 の有休の行 | F-101、F-405 |
| M-4 | 日を選ぶ面 | 面 | 祝日のない月の候補の「日を選ぶ」 | F-205 |
| M-5 | 会社の休日の面 | 面 | S-2 の会社の休日の行、「＋ 会社の休日を足す」 | F-103 |
| M-6 | 休暇の種類の面 | 面 | S-2 の休暇の種類の行、「＋ 休暇の種類を足す」 | F-104 |

主な画面には 2 つの状態がある。

- **設定なし**: 付与日を入れていない。持ち分は出さず、入力を誘う（F-106）
- **設定あり**: 付与日を入れた。持ち分を出す

2 つの状態を分けるのは付与日の有無だけで、変わるのは持ち分の出し方だけ。候補と連休の計算には、付与日がなくても、登録してある会社の休日と日程を入れる（F-103、F-207、R-1）。足した休暇の種類の持ち分も、付与日がないあいだは出さない（付与年が決まらないため）。

最初に返す HTML（N-04）には次のものを入れる（Claude の案）。

- サービスの説明文（§3.1）
- ビルドした年の 1 月から、祝日が確定している期間までの四半期ごとの見出しと、候補の一覧（土日と祝日だけで計算したもの。実装計画 1 の `staticCandidateGroups`）
- 祝日の 1 行（§3.10）

月カレンダー、長めの休暇の 1 行、持ち分、日程は、端末で描く。端末は記録を読んだあと、今日が入る四半期から 4 つに絞り、記録を入れて計算し直した内容に差し替える。差し替えるまでのあいだ、持ち分の場所は高さを保ったまま空けておき、誘いのカードを一瞬出すことはしない。スマホと PC の配置は CSS で切り替え、HTML は 1 つにする。差し替えのときのちらつきを抑える方法は、実装計画で決める。

幅 1024px 未満をスマホの配置、1024px 以上を PC の配置とする（Claude の案。bassdrill と同じ境目）。

## 3. 主な画面（スマホ）

### 3.1 構成

上から順に並べる。

```
┌──────────────────────────────┐
│ 連休プランナー           設定 │  ヘッダー
├──────────────────────────────┤
│ 有休 残り                     │  持ち分のカード（§3.2）
│ 9日2時間                      │  設定なしのときは誘いのカード（§3.9）
│ 予定 2日・未割り当て 7日2時間 │
├──────────────────────────────┤
│ 長めの休暇                    │  長めの休暇の 1 行（§3.3）
│ [10〜12月 あり][1〜3月 まだ]… │
├──────────────────────────────┤
│‹前│2026年 │2027年│2027年│2027年│  四半期のタブ（§3.4）
│   │10〜12月│1〜3月│4〜6月│7〜9月│
├──────────────────────────────┤
│ 2026年 10〜12月               │  タブの中身（§3.5）
│ 長めの休暇: 12/26〜1/3（9連休）│   長めの休暇
│ [10月] [11月] [12月]          │   月カレンダー（§3.6）
│ 候補                          │   候補（§3.7）
│ 日程               ＋ 日を足す │   日程（§3.8）
├──────────────────────────────┤
│ 祝日は内閣府の公表データです…  │  祝日の 1 行（§3.10）
└──────────────────────────────┘
```

ヘッダーは画面の上に固定しない。スクロールすると一緒に流れる（Claude の案）。

設定なしのときは、ヘッダーのすぐ下にサービスの説明文を 1〜2 行で出す（N-04。文は `APP_DESCRIPTION`）。設定ありのときは出さない（Claude の案。最初に返す HTML は設定なしの内容なので、検索エンジンには説明文が届く）。

### 3.2 持ち分のカード

休暇の種類ごとに 1 枚出す（F-401）。出すのは、今日が入る付与年の値。

| 行 | 内容 | 例 |
|---|---|---|
| 1 行目 | 休暇の種類の名前と「残り」 | 有休 残り |
| 2 行目 | 残りの量。大きな文字 | 9日2時間 |
| 3 行目 | 予定の量と、未割り当ての量 | 予定 2日・未割り当て 7日2時間 |

- 量の書き方は R-11 のとおり（「9日2時間」。モックでは日と時間のあいだを詰めている。R-11 の「9 日と 2 時間」とどちらにするかは §8 で決める）
- 未割り当てが負のときは、「未割り当て」の代わりに「不足 1日」と出し、警告の色にする（F-211、R-11）。0.5 分の端数で絶対値が 1 分に満たないときは「不足」を出さず「未割り当て 0日」とする（Claude の案）
- 使える期間のある休暇の種類は、3 行目に期間を添える（例: 「7〜9月」）。残りが 0 なら「使い切り」と出す
- カードが 2 枚のときは横に並べる。3 枚以上は横にスクロールする（Claude の案）
- 付与年の終わりが近いのに未割り当てが残っているときは、カードの下に 1 行出す（F-404）。例: 「4/30 まであと 45日。7日2時間がまだ決まっていません」。「近い」は付与年の末日まで 90 日以内とする（Claude の案。§9 V-3）。使える期間のある休暇の種類も、期間の末日について同じ行を出す（F-406）

### 3.3 長めの休暇の 1 行

持ち分のカードのすぐ下に置く（P-3）。見出し「長めの休暇」を 1 回だけ書き、その下に、タブに並んでいる 4 つの四半期の状態を小さな札で並べる。

- 札の文言: 「10〜12月 あり」「1〜3月 まだ」。あり・まだで色を変える
- 判定は R-14
- 会社の休日も日程も 1 件も登録していないときは、見出しを「長めの休暇（土日と祝日だけで計算）」とする
- 並べるのは、いつも今日が入る四半期からの 4 つ。「‹ 前」でタブがずれても、この行は変えない（Claude の案）
- 札は押せない（Claude の案。押してその四半期のタブを開く動きは足さない）

### 3.4 四半期のタブ

- 左端に「‹ 前」、続けて 4 つの四半期を並べる。タブは 2 行で、上に年（「2026年」）、下に月（「10〜12月」）
- 最初に開くのは、今日が入る四半期
- 「‹ 前」を押すと、タブの並びが 1 四半期ぶん前へずれ、いちばん左の四半期を開く。前へずれているあいだは、右端に「次 ›」を出す。「次 ›」で 1 四半期ぶん戻る（Claude の案）。前へ動ける限りは、記録（日程）がある最も古い四半期までとする（Claude の案）
- タブの題に、長めの休暇の有無や付与日は入れない（オーナー決定。§3.3 と §3.6 に出す）
- タブの段はスクロールしても画面の上に張り付く（F-507。Claude の案）
- 持ち分のカードが画面の外へ流れたあとは、タブの段のすぐ上に、持ち分を 1 行に縮めたものを一緒に張り付ける（F-401。オーナー決定）。例: 「有休 残り 9日2時間・未割り当て 7日2時間」。休暇の種類が 2 つ以上あるときは有休だけを出す（Claude の案）。未割り当てが負のときは「不足 1日」と警告の色で出す。設定なしのときは出さない
- 過ぎた四半期（末日が今日より前の四半期）の中身は、見出し、長めの休暇、月カレンダー、日程だけにする。候補の欄と、カレンダーの候補の印は出さない（Claude の案。R-4 により、今日より前の日は候補にならない）

### 3.5 タブの中身

上から、見出し、長めの休暇、月カレンダー、候補、日程の順（オーナー決定）。

- 見出し: 「2026年 10〜12月」
- 長めの休暇: あるときは「長めの休暇: 12/26〜1/3（9連休）」と「あり」の札。ないときは「長めの休暇: まだない」（F-403）

### 3.6 月カレンダー

その四半期の 3 か月を横に並べる（F-502）。

- 日曜始まり。見出しは「10月」。曜日の行は「日月火水木金土」
- 日ごとの色分けは次のとおり。重なったときは上の行を優先する

| 順 | 種類 | 見た目（仮） |
|---|---|---|
| 1 | 取得済みの日程 | 塗りつぶし（主色） |
| 2 | 予定の日程 | 枠線（主色） |
| 3 | 候補の休む日 | 枠線（注意の色）と薄い地 |
| 4 | 会社の休日 | 薄い地（青系） |
| 5 | 土日・祝日 | 薄い地（赤系） |

- 半日・時間単位の日程の日も取得済み・予定の印で出す（Claude の案）
- 候補の印を付けるのは、§3.7 でその四半期に出している候補（組の代表）の休む日だけ
- 付与日は上の色分けとは別に、日付に紫の枠を重ねる（オーナー決定）。その付与日が、今日より後に来る付与日（次の付与年の始まり）のときは、カレンダーの下に 1 行添える。今の付与年の始まりに当たる付与日には、枠だけを付けて 1 行は添えない（Claude の案）
  - 次の付与年の日数を入れていないとき: 「5/1 から次の付与年（前の年と同じ 14日で計算中）」と「日数を入れる」。「日数を入れる」は M-3 を開く
  - 入れたあと: 「5/1 から次の付与年（有休 16日）」
- カレンダーの下に凡例を置く。その四半期に出ている種類だけを並べる（Claude の案）
- 日付のマスは押せない（Claude の案。§9 V-4）

### 3.7 候補

見出し「候補」の下に、その四半期の候補の組を R-7 の順で並べる。1 つの組は 1 行で、組の代表の候補（要件定義書 §5.1）を出す。

| 部分 | 内容 | 例 |
|---|---|---|
| 1 行目 | 休む日と曜日、連休の日数 | 11/20(金) を休むと 4連休 |
| 札 | 5 連休以上なら「長め」（F-204）。未確定なら「祝日が未確定」（F-210） | |
| 2 行目 | 連休の期間。次の付与日以降の日を含むなら「次の付与年から引く」（F-209） | 11/20〜11/23 |
| ボタン | 「日程に入れる」。M-1 を開く | |

- 休む日が 2 日以上のときは「12/28(月)・12/29(火) を休むと 9連休」と書き、2 行目に使う日数を添える（「12/26〜1/3・2日使う」）（F-202）
- 組にほかの候補があるときは、行の下に「ほかの取り方（2）」を出す。押すと、同じ組の残りの候補が R-7 の順で開く。それぞれに「日程に入れる」が付く（F-203。Claude の案。§9 V-5）
- 未割り当てが足りない候補も出す。2 行目に「有休が 1日足りません」と添える（F-211）。判定は、休む日が入る付与年ごとに、その付与年の未割り当てで行う（次の付与年の未割り当ては R-13 の初期値で数える）。休暇の種類は M-1 で初期値になる種類（ふつうは有休。F-208 に当たるときはその休暇）で見る（Claude の案）
- 祝日のない月の候補（R-8）は、通常の候補の下に並べる。1 行目は「6月は祝日がありません。金曜か月曜を休むと 3連休」、ボタンは「日を選ぶ」で M-4 を開く
- その四半期に候補が 1 つもないときは「この四半期の候補はありません」と出す

### 3.8 日程

見出し「日程」の右に「＋ 日を足す」を置く（M-2 を開く）。その下に、その四半期の日付の日程を、日付の早い順に並べる。

- 1 日 1 行（オーナー決定）。行の中身は次のとおり

| 部分 | 内容 | 例 |
|---|---|---|
| 1 行目 | 日付と曜日、量、予定の名前 | 12/28(月) 1日 年末年始 |
| 2 行目 | 状態（予定・取得済み）。有休以外なら休暇の種類の名前 | 予定 |
| 右端 | 「›」。行を押すと M-2 を開く | |

- その日が 3 日以上の連休に入るとき（F-304）
  - 同じ連休に入る日程が 2 件以上なら、連休の見出し（「12/26〜1/3 の 9連休」と、5 連休以上なら「長め」の札）を 1 行置き、その下に日程を並べる
  - 1 件だけなら見出しを置かず、2 行目に「取得済み・10/31〜11/3 の 4連休」のように添える
- 日付を過ぎた予定は 2 行目を「予定・日付を過ぎています」として警告の色にし、右端を「取得済みにする」のボタンに替える（F-305）。押すと、面を挟まずに取得済みになる。行のほかの場所を押すと M-2 を開く
- 休みの日と重なった日程（R-17）は、2 行目に「休みの日と重なっています」を警告の色で添える。行を押して M-2 を開き、利用者が消す
- 日程が 1 件もないときは「まだありません」と出す

### 3.9 設定なしのとき

持ち分のカードの場所に、誘いのカードを置く（オーナー決定）。

```
┌──────────────────────────────┐
│ 有休の残りを出す              │
│ 付与日と日数を入れると、残りと、│
│ まだ日を決めていない日数が出ます│
│ [付与日と日数を入れる]         │
└──────────────────────────────┘
```

- ボタンは M-3 を開く
- 設定なしでも、候補を日程に入れる操作と、日を足す操作はできる。M-1 と M-2 では持ち分に関わる行（引く休暇の残り、未割り当ての変化）を出さず、代わりに「付与日と日数を入れると、残りが出ます」を出す（Claude の案）

### 3.10 祝日の 1 行

画面のいちばん下に出す（F-605）。

- 文: 「祝日は内閣府の公表データです。2027年12月31日まで確定。」と「くわしく」
- 「くわしく」は S-2 を開き、「祝日について」の節まで動かす

### 3.11 保存できないとき

ブラウザの保存領域が使えないとき（N-08）は、ヘッダーのすぐ下に 1 行出す。「このブラウザでは記録を保存できません。閉じると、入れた内容は消えます。」候補はそのまま見られる。

## 4. 主な画面（PC）

スマホと同じ中身を、次のように並べ替える（オーナー決定）。違う所だけを書く。

```
┌────────────────────────────────────────────────────────┐
│ 連休プランナー                                      設定 │
├────────────────────────────────────────────────────────┤
│ [有休 残り 9日2時間 …]  長めの休暇 [10〜12月 あり][…]    │
├────────────────────────────────────────────────────────┤
│ 2026年 10〜12月            │ 候補                        │
│ 長めの休暇: 12/26〜1/3…     │  11/20(金) を休むと 4連休 [日程に入れる] │
│ [10月] [11月] [12月]        │ 日程               ＋ 日を足す │
│ 凡例                        │  10/7(水) 2時間 体調不良 …   │
├────────────────────────────────────────────────────────┤
│ 2027年 1〜3月              │ 候補 …                       │
│ …（4 つの四半期を縦に並べる）                             │
├────────────────────────────────────────────────────────┤
│ 祝日は内閣府の公表データです。…くわしく   過ぎた四半期の記録を見る │
└────────────────────────────────────────────────────────┘
```

- タブを置かない。今日が入る四半期から 4 つの節を、開いたまま縦に並べる
- 持ち分のカードと、長めの休暇の 1 行は、横に並べる
- 四半期の節は 2 列。左に見出し、長めの休暇、月カレンダー、凡例、付与日の 1 行。右に候補と日程
- 節の見出し（「2026年 10〜12月」）は、その節をスクロールしているあいだ、画面の上に張り付く（F-507。Claude の案）
- 過ぎた四半期は、いちばん下の祝日の 1 行と同じ段の右端に置いた「過ぎた四半期の記録を見る」から開く（P-5。オーナー決定）。押すたびに、1 つ前の四半期の節を、並びのいちばん上に足す。足したあとは、その節まで画面を動かす（Claude の案）。過ぎた四半期の節の中身は §3.4 と同じ（候補の欄を出さない）
- 本文の幅は最大 960px とし、画面の中央に置く（Claude の案）
- 面は画面の中央に出す。ボタンは面の右下に並べる。「この日程を消す」のような消す操作は、左下に離して置く

## 5. 面

共通の決まり。

- 閉じ方は 3 つ。「やめる」を押す、面の外を押す、PC では Esc キーを押す。どれも、入れかけの内容を捨てる
- 確定のボタンは 1 つで、主色で塗る。入れた内容が受け付けられないあいだは押せない見た目にし、理由を該当の欄の下に出す（文言は §8.3）
- 面を開いているあいだ、下の画面は暗くし、スクロールさせない

### 5.1 M-1 日程に入れる面

候補の休む日を、予定として日程に入れる（F-206）。

| 行 | 内容 | 例 |
|---|---|---|
| 題 | 日程に入れる | |
| 休む日 | 休む日と合計の量 | 11/20(金) 1日 |
| 連休 | 期間と日数 | 11/20〜11/23 の 4連休 |
| 引く休暇 | 休暇の種類と、その残り。種類が 2 つ以上あるときだけ選べる | 有休（残り 9日2時間） |
| 未割り当て | 入れる前と後。休む日が入る付与年の値 | 7日2時間 → 6日2時間 |
| 予定の名前 | 任意の入力欄 | |
| ボタン | 「予定に入れる」「やめる」 | |

- 休む日が付与日をまたぐときは、未割り当ての行を付与年ごとに 2 行出す（例: 「今の付与年 7日2時間 → 6日2時間」「次の付与年 14日 → 13日」）（F-209）
- 使える期間のある休暇の種類に残りがあり、休む日がその期間に入るときは、引く休暇の初期値をその種類にする（F-208）
- 入れると未割り当てが負になるときも入れられる。未割り当ての行を「7日2時間 → 不足 1日」と警告の色で出す（F-211）
- 「予定に入れる」を押すと、面を閉じ、日程の欄に行が増える。休む日の数だけ、1 日分の日程を作る。予定の名前は全部の日に同じものを入れる

### 5.2 M-2 日程の面

| 行 | 内容 | 備考 |

- 日付が休みの日のときは保存できない（R-17）。すでに休みの日と重なっている日程を開いたときは、理由を出したうえで、消す操作だけを受け付ける
- 同じ日の量の合計が 1 日を超えるときは、量の欄の下に知らせを出す。保存はできる（F-306）

## 6. 設定の面（S-2）

主な画面とは別の 1 枚（F-504）。左上の「‹ 戻る」で主な画面へ戻る。スマホと PC で同じ並びにし、PC では本文の幅を最大 640px にする（Claude の案）。変えた内容はその場で保存し、主な画面に戻ると計算し直した結果が出る（F-107）。

上から次の節を並べる。

| 節 | 行 | 押したとき |
|---|---|---|
| 有休 | 付与日（「5月 1日」） | M-3 |
| | 付与年ごとに 1 行（「2026/5/1〜2027/4/30　付与 14日・繰り越し 0日」）。今日が入る付与年と、その次の付与年を出す。次の付与年が未入力なら「日数を入れる（いまは 14日で計算）」 | M-3 |
| | 過ぎた付与年があれば「過ぎた付与年を見る」。押すと、その行が開く（F-405） | |

| 会社の休日 | 登録した休日ごとに 1 行（「12/30〜1/3　毎年」）と「＋ 会社の休日を足す」 | M-5 |
| 休暇の種類 | 種類ごとに 1 行（「有休　消せません」「夏季休暇　3日・7/1〜9/30」）と「＋ 休暇の種類を足す」 | M-6 |

## 8. 文言

### 8.1 方針

モックと本書の文言は仮のもの。要求定義書 §4.1 の用語は文書の中で意味をそろえるための言葉で、前提を知らない利用者には伝わらない（オーナー指摘）。配置が固まったあと、画面に出す言葉をまとめて決め、下の表を埋める。決まるまでは、実装でも仮の文言を使い、文言を 1 か所（定数のファイル）に集めておく。

題と説明文は「有給」を使う（要求定義書 §9）。画面の中を「有休」「有給」のどちらにそろえるかは未決（§9 V-1）。
